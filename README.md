# 脑图编辑器 · MindMap Studio

一款纯前端的脑图编辑工具，支持本地多文档管理、脑图与 Markdown 双向同步、拖拽整理、撤销重做和本地自动保存。

## 启动

安装依赖并启动 Vite 开发服务器：

```bash
npm install
npm run dev
```

生产构建与本地预览：

```bash
npm run build
npm run preview
```

> 推荐使用 Chrome / Edge / Firefox 最新版。

## 功能特性

- ✏️ **自由编辑**：双击节点即可编辑文本
- 🎯 **拖拽节点**：按住节点拖动，位置自动保存
- 🔍 **缩放/平移**：滚轮缩放，拖拽空白处平移，按 `F` 适应屏幕
- 🎨 **星图工作台**：以画布为中心，节点工具和导航按需出现
- 🔁 **双向同步**：脑图改名、增删节点会同步 Markdown；Markdown 结构或文本变化会同步脑图
- 🌓 **三种视图**：脑图、Markdown、分屏，文字稿按需打开并支持节点与行号互相定位
- 📂 **文件操作**：直接打开 / 导出 Markdown，支持 JSON 备份恢复
- ↩️ **撤销重做**：支持按钮和 `Ctrl/Cmd + Z`、`Ctrl/Cmd + Shift + Z`
- 🌙 **深色主题**：一键切换，自动记忆
- 💾 **本地文档库**：IndexedDB 自动保存，支持搜索、复制、回收站与恢复，兼容迁移旧版 localStorage 数据
- 📑 **缩略图 & 大纲**：通过导航按钮按需打开
- ⊕ **折叠/展开**：复杂节点可折叠（显示子节点数量）
- 🔗 **工作流连线**：点击或拖动节点外侧 `+` 拉出连线，接到目标输入端口；落到空白处可先命名再创建节点
- 🧭 **层级整理**：`Shift + 拖拽` 将节点挂到目标节点下

## 快捷键

文档仅保存在当前浏览器。请保持访问地址与端口不变，并定期导出 JSON 备份；清除站点数据会删除本地文档。

| 按键 | 功能 |
| --- | --- |
| `Tab` | 创建子节点 |
| `Enter` | 创建同级节点 |
| `F2` | 编辑当前节点 |
| `Delete` / `Backspace` | 删除节点 |
| `Space` | 折叠/展开节点 |
| `F` | 调整到可读视图 |
| `Shift + 拖拽` | 将节点挂到目标节点下 |
| `节点外侧 +` | 拉出连线；接到输入端口或空白处 |
| `Delete` / `Backspace` | 选中连线时删除连线 |
| `滚轮` | 缩放 |
| `拖拽空白处` | 平移画布 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` | 重做 |
| `Ctrl/Cmd + Enter` | 立即应用 Markdown |
| `Esc` | 取消选择 |

## Markdown 格式

支持两种格式，可混用：

```markdown
# 中心主题        ← 第一个 # 标题作为根节点文本

## 分支一         ← 二级标题作为分支
- 列表项          ← 标题后列表属于最近的标题节点
  - 嵌套项        ← 每缩进 2 空格再深入一层
### 子项 A         ← 三级标题作为子项
```

在顶部切换「脑图 / Markdown / 分屏」即可使用两种编辑方式。Markdown 输入停止约 300ms 后自动应用，也可以按 `Ctrl/Cmd + Enter` 立即应用。

编辑 Markdown 时，停止输入约 300ms 后会自动检查并整理内容：普通文本首行会转换为根标题，后续普通文本会转换为列表节点；普通说明行后紧跟的列表会自动缩进为该说明的子节点，同时保留原有行数和光标位置。支持标题、列表、引用块和分隔线语法；分隔线仅用于排版，不会生成节点，引用块会作为当前标题下的说明节点。

工作流连线是脑图层级之外的有向关系，保存在 JSON 和本地数据中，不会改变 Markdown 的层级结构；Markdown 修改节点文本或层级时，会尽量保留仍存在节点之间的连线。点击节点外侧 `+` 后，拖到目标输入端口即可连接已有节点；拖到空白处会弹出节点命名框，确认后才创建新节点。连线采用 DAG 约束，不能连接自身、重复连线或制造循环。

## 数据存储

- 所有节点数据自动保存在浏览器 `localStorage`（当前键名 `mindmap-studio-v2`，兼容读取 v1）
- 关闭浏览器后再次打开会自动恢复
- 「清空」按钮会重置整个脑图（需确认）
- 重要内容建议定期「导出 JSON」备份

## 技术要点

- 使用 Vue 3 + TypeScript + Vite 组织应用，Vue 组件负责界面宿主，编辑器核心负责高频画布交互。
- 节点使用 HTML `<div>` 渲染（便于富文本编辑和事件交互）
- 连接线使用 SVG `<path>` 贝塞尔曲线和输入/输出端口，交互模型参考 Coze/FlowGram 工作流画布
- 画布使用 CSS `transform: translate + scale` 实现硬件加速的平移缩放
- 响应式设计：窗口缩放时缩略图和视图自动适配
